# CS61A — Concepts

## 递归先确定返回类型

递归调用解决一个更小的同类问题；每条分支都必须遵守同一返回约定。判断“存在”通常用 any 合并，判断“全部”用 all，收集结果才用列表。非空列表即使只含 False，其真值仍为 True，因此列表不能替代布尔结果。

## Base case 与状态含义

给每个参数写一句定义：它表示已经处理过的量，还是仍需处理的量？终止条件必须与这个定义一致。先用最小输入检验是否漏算当前元素。依赖单调性的提前停止，需要先证明输入满足单调性；整数类型并不等于非负整数。

## 树结构与对象

叶节点由“没有子分支”定义，与 label 是否为 None 无关。构造新树与修改原树有不同的副作用；共享引用会让修改影响其他持有者。具体叶节点接口取决于 Tree 的实现，不混用函数式与对象式 API。

## Dictionary comprehension

通用形式是 {key_expr: value_expr for item in iterable}。key 与 value 可以是不同类型；取值返回的是 value，重复 key 的后一次赋值会覆盖之前的 value。
