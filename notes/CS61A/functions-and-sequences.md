# 函数、返回值与序列

## 函数对象不等于调用结果

f 是函数对象，f(x) 才是调用。return f 返回函数，return f(x) 返回调用结果。print 的输出是副作用，return 的值交给调用者；赋值语句不会自动显示其右侧返回值。Python 交互环境可能显示表达式的结果，脚本里的裸表达式一般不会显示。

## 连续调用与闭包

build(a)(b)(c) 可以拆成 p=build(a)、q=p(b)、result=q(c)，逐层检查返回类型。返回的函数可以通过词法作用域引用外层变量；闭包捕获的并非一定是不可变的值快照。lambda x: x 是恒等函数，适合“零次变换”的基例。

## 递归结果如何汇合

每层只对自己的返回值负责。单分支可以直接返回子调用得到的列表；上层若有多个分支，再将各列表拼接。不要把这种合并误认为所有调用在自动共享一个全局列表。

## Tuple 与 linked list

Tuple 是不可变序列；单元素写作 (value,)。不可变指元素引用不能被重新赋值，其中引用的可变对象仍可改变。空 tuple 可被某种链表实现选作空节点标记，但不是所有链表的通用规定。访问 first/rest 前先判断是否为空。逐元素建表的辅助函数与接受“头元素+尾链表”的节点构造器不是同一接口。

## min 的 key

key 指定比较用的量，min 返回原始元素而非 key 的结果。并列时返回首次遇到的最小项；空输入需考虑 default 或异常。
