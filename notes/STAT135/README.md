# STAT135 学习笔记

本目录仅保存允许公开的概念、通用误区和原创示例。禁止提交受限作业答案、题目特定解法、测试细节、个人隐私或原始聊天记录。内容是否允许公开不明确时，保留在私有仓库待审查。

## Concepts

尚无学习条目。按主题持续补充：概念、直觉解释、适用条件、原创示例、相关概念。

## Mistakes

尚无错题或误区条目。记录：当时的理解、出错原因、正确解释、下次如何识别。
