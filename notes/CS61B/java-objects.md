# Java 对象与语法

## 声明、初始化与导入

import 使类型名可被简写，不会创建实例，也不能代替配置依赖。引用字段只声明未赋值时通常为 null；new 调用构造器创建对象。局部变量则需要在读取前满足确定赋值规则，不能套用字段默认值规则。

## Constructor 与命名习惯

构造器名称必须与类名一致且没有返回类型，这是语法要求。类名首字母大写、变量名小写开头通常属于命名约定。声明 void ClassName(...) 是普通方法，不是构造器。

## Static 与 instance

static 方法属于类，没有隐含的 this；可通过显式对象引用访问实例内容。实例方法对某个对象工作，可访问该对象状态。多个对象通常各自拥有实例字段，而 static 字段属于类。

## Java if 与二维索引

Java 的条件必须是 boolean，不接受用整数直接代替条件。二维坐标展开为一维下标时，一维相邻不必然是二维邻居：每行末尾与下一行开头就是反例。先确认几何边界再计算邻居。

## IDE 提示的证据边界

标红、变灰可能来自依赖、作用域、未使用符号等不同原因。颜色本身不足以断定错误类型，应读诊断、核查声明和初始化路径。
